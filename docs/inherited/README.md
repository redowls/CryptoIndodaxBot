# Inherited design docs

These are **CryptoAutoBot's original design documents**, copied verbatim on
2026-09-01 when this bot was ported. They are kept for the strategy rationale —
why the regime gate, entry filters, exit rules and policy clamps are shaped the
way they are — which carried over to Indodax unchanged.

They are **not** accurate about this bot's plumbing. Everything they say about
Alpaca, USD pairs, paper trading, bar pagination or the broker client has been
replaced; see the "What changed from CryptoAutoBot" table in the root README.
